# Davy

[![Davy version](assets/version.svg)](https://davy.raintechsolutions.com/docs/changelog)

Davy is a multiplatform framework for building geospatial applications with plugins.
This repository is the public home for Davy bug reports, feature requests,
community discussions, and SDK examples. Davy's core source and development are
maintained internally by Rain Technology Solutions.

## Bugs and feature requests

[Open an issue](https://github.com/Rain-Technology-Solutions-Inc/Davy-Public/issues)
for a reproducible bug, a concrete enhancement, or a documentation correction.
Search existing issues first and add relevant details to an existing report when
possible.

For bugs, include your Davy version, platform or browser, affected plugin, steps
to reproduce, and the expected and actual behavior. Screenshots and relevant
logs are helpful; remove credentials and private data before posting them.

For enhancements, describe the task you're trying to accomplish and how the
change would help. The Davy team reviews reports, applies labels, and manages
the issue board. An issue being submitted does not commit it to a release.

## Questions and ideas

Use [Discussions](https://github.com/Rain-Technology-Solutions-Inc/Davy-Public/discussions)
for questions, early ideas, and sharing what you're building. Use the linked
documentation for setup and API guidance.

Repository changes are maintained by the internal team. Public participation is
welcome through Issues and Discussions; this repository does not accept pull
